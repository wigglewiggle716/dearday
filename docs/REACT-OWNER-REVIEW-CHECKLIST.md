# Dear Day — قائمة مراجعة واعتماد نقل الموقع إلى React

**Version:** 2026-10-10 • **Owner checklist** • Branch: `react-migration` • React Vercel project: `dearday-react-migration`

هذه هي **القائمة الرئيسية والتراكمية** لجميع التعديلات المطلوب من مالك Dear Day تجربتها بنفسه قبل أي اعتماد أو تحويل الدومين. كل البنود أدناه **غير معتمدة حتى يختبرها المالك**. سنحدّث نفس الملف في كل مرحلة جديدة بدل إنشاء قائمة مراجعة منفصلة.

**تعريف الحالات:** `[CODE]` مطبّق بالكود على فرع React ولكن يحتاج نشرًا واختبارًا. `[PARTIAL]` جزء من الرحلة مطبّق وما زال هناك اعتماد على النظام القديم. `[GATE]` إجراء خطير أو قرار إطلاق يحتاج مراجعة منفصلة. `[LATER]` جزء من الانتقال لم يكتمل. علامة `[ ]` تظل فارغة حتى يراجعها المالك بنفسه؛ علامة `[x]` لا تستخدم دون تأكيده.

**قاعدة الأمان:** لا تغيّر `main`، ولا تنقل `dear-day.com` من المشروع القديم، ولا تطبّق SQL على Supabase المشترك، ولا ترسل رسائل للعملاء، ولا تعدّل طلبات حقيقية أثناء مراجعة النسخة الجديدة.
